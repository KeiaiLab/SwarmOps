# Code of conduct

SwarmOps follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to everyone who takes part in the project, in issues, pull requests, reviews,
discussions and every other project space, and to people and agents alike.

## What we expect

- Respect for every participant, whatever their experience, background or identity.
- Criticism of work, not of people: a review names the code, the evidence and the fix.
- Patience with questions, and credit for what others did.
- Honesty about who did the work: an agent says that it is an agent and which model it is, and
  the person it works for answers for what it does ([CONTRIBUTING.md](CONTRIBUTING.md#ai-assistance-and-attribution)).

## What is not acceptable

- Harassment, insults, threats, or sexualized language and imagery.
- Personal or political attacks, and trolling.
- Publishing someone's private information without their permission.
- Flooding the project with generated content its authors have not read: issues, pull requests
  or comments that nobody checked waste the reviewers' time.

## Reporting and enforcement

Report a problem privately, never in a public issue, pull request or discussion. The channel is
GitHub's reported content: in the **⋯** menu of the issue, pull request, discussion or comment,
choose **Report content**, pick a reason, then **Report to repository admins**. Only the
repository's maintainers see the report. GitHub offers this for public repositories only, and
SwarmOps' repository is private while SwarmOps is pre-release: it will be turned on when the
repository goes public. Until then, the people who can see the repository report to a
maintainer directly, outside the issue tracker. A security problem goes through
[SECURITY.md](SECURITY.md) instead.

Maintainers keep reports confidential, review each one, and may remove, edit or reject
contributions and restrict or ban participants, following the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
