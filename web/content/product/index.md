description: 'A git replacement for coding-agent swarms: many writers, one store, one JSON envelope per command.'
---

SwarmOps is a git replacement for coding-agent swarms: many agents commit into one embedded store
at once, every command answers in JSON, and the work moves back to git. It is written in Rust and
fully embedded: one program, no external database, no daemon.

Read the [documentation](/docs) to install it and make a first commit.
